# 🛍️ AURAWEAR — AI-Powered Fashion & E-Commerce Platform

> Next-generation fashion e-commerce experience featuring intelligent style profiling, wardrobe optimization, 3D virtual try-on, trend radar, and occasion-based outfit orchestration.

---

## 🌟 Overview

**AURAWEAR** blends modern streetwear and luxury aesthetics with intelligent interactive fashion tools. Designed with a sleek dark-gold aesthetic, it moves beyond traditional product listing pages into an interactive fashion companion.

### ✨ Key Features

- **🛍️ Dynamic E-Commerce Catalog**:
  - Filter by category (Tops, Bottoms, Outerwear, Footwear, Accessories) and style tags (*streetwear*, *minimal*, *luxury*, *casual*, *formal*).
  - Natural-language "Ask AI" search interface with smart keyword filtering.
  - Interactive product detail view with multi-size selection and real-time inventory checks.
- **✨ AI Style Twin & Profiling**:
  - Personalized measurement tracking & fit preferences.
  - Tailored trend alerts and style recommendations based on user affinity.
- **👗 Wardrobe Optimizer**:
  - Visual wardrobe tracker to catalog existing clothes by color and category.
  - Gap-analysis engine suggesting smart additions to complete diverse looks.
- **🕶️ 3D Virtual Try-On**:
  - Rotatable 3D avatar preview powered by **React Three Fiber**.
  - Intelligent sizing recommendations and returns probability estimation.
- **🎯 Smart Occasion Agent**:
  - Generates complete multi-item lookbooks (top + bottom + footwear + accessories) based on occasion prompts (e.g. *beach party*, *tech interview*, *cocktail gala*).
  - One-click "Add Full Look to Cart" workflow.
- **🛒 Persistent Shopping Cart & Checkout**:
  - Context-driven slide-out drawer with quantity controls, subtotal computation, and frictionless checkout flow.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/tanisksahu/AURAWEAR.git

# Navigate to frontend
cd AURAWEAR/frontend

# Install dependencies
npm install

# Start local development server
npm run dev
```
